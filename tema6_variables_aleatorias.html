Variables Aleatorias

Convierte los resultados de un experimento en números que podemos calcular. La base de toda la estadística.

1. ¿Qué es una Variable Aleatoria?

Una variable aleatoria (X) es una función que asigna un número a cada resultado de un experimento. O sea, convierte resultados en números que podemos calcular.

📌 Ejemplo: Lanzar dos monedas

Experimento: Lanzas 2 monedas y cuentas cuántas caras salen.

Resultado Valor de X (nº de caras)
(C, C) 2
(C, K) 1
(K, C) 1
(K, K) 0

La variable X toma valores {0, 1, 2} — ese conjunto de valores es la variable aleatoria.

Tipos de variables aleatorias

Discreta

Toma valores contables (0, 1, 2, 3...). Generalmente es un conteo.

📌 Ejemplo: Nº de clientes por hora

\[ E[X] = \sum x \cdot P(X=x) \]

Continua

Toma cualquier valor en un intervalo. Generalmente es una medición.

📌 Ejemplo: Peso, estatura, tiempo

\[ E[X] = \int x \cdot f(x) \, dx \]

2. Valor Esperado (E[X])

Es el valor promedio que esperas obtener si repites el experimento muchas veces. Es la media ponderada por las probabilidades.

Fórmula
\[ E[X] = \sum x \times P(X=x) \]

📌 Ejemplo: Restaurante de hamburguesas

Contexto: El restaurante rastrea cuántas hamburguesas venden por hora.

x (hamburguesas/hora) P(X=x) x × P(x)
0 0.05 0
1 0.15 0.15
2 0.30 0.60
3 0.25 0.75
4 0.15 0.60
5 0.10 0.50
SUMA 2.60
\[ E[X] = 0 + 0.15 + 0.60 + 0.75 + 0.60 + 0.50 = 2.60 \]

Interpretación

En promedio venden 2.6 hamburguesas por hora. No significa que siempre vendan 2 o 3, es el promedio a largo plazo.

3. Varianza y Desviación Estándar

La varianza mide cuánto se dispersan los valores alrededor de la media. La desviación estándar es la raíz cuadrada de la varianza y se interpreta en las unidades originales.

Fórmulas
\[ \text{Var}[X] = E[X^2] - (E[X])^2 \]
\[ E[X^2] = \sum x^2 \times P(X=x) \]
\[ \sigma = \sqrt{\text{Var}[X]} \]

📌 Ejemplo: Continuando con el restaurante

Contexto: Sabemos que E[X] = 2.60. Ahora calculamos E[X²].

x P(x) x² x² × P(x)
0 0.05 0 0
1 0.15 1 0.15
2 0.30 4 1.20
3 0.25 9 2.25
4 0.15 16 2.40
5 0.10 25 2.50
SUMA 8.50
1

Calcular E[X²]: 0 + 0.15 + 1.20 + 2.25 + 2.40 + 2.50 = 8.50

2

Calcular la varianza:

\[ \text{Var}[X] = 8.50 - (2.60)^2 = 8.50 - 6.76 = 1.74 \]
3

Calcular la desviación estándar:

\[ \sigma = \sqrt{1.74} = 1.32 \]

Interpretación

En promedio, la venta de hamburguesas varía ±1.32 de las 2.6 esperadas por hora.

Resumen Rápido

Concepto Fórmula ¿Qué mide?
Valor esperado \[ E[X] = \sum x \times P(x) \] El promedio esperado
Varianza \[ E[X^2] - (E[X])^2 \] La dispersión al cuadrado
Desv. estándar \[ \sqrt{\text{Var}[X]} \] Dispersión en unidades originales

Dato clave

  • Discreta → suma (Σ)
  • Continua → integral (∫)
  • E[X] siempre está entre el valor mínimo y máximo de X
  • La varianza nunca es negativa
