Tema 1: Fundamentos

Población, muestra, variables y escalas

Población vs Muestra

Población: Todos los elementos que nos interesan (ej: todos los estudiantes de Colombia)

Muestra: Un subconjunto de la población (ej: 500 estudiantes encuestados)

Variables Categóricas

Nominal: Sin orden (género, color de ojos)

Ordinal: Con orden (nivel de dolor, ranking)

Variables Numéricas

Discreta: Se cuentan (nº de hijos, nº de autos)

Continua: Se miden (estatura, peso, tiempo)

💡
Truco para recordar

Discreta: ¿Se puede contar? 1, 2, 3... → Discreta
Continua: ¿Se puede medir con decimales con sentido? → Continua

Ejemplo práctico

Una encuesta pide: género (nominal), nivel de estudios (ordinal), edad (continua), nº de hermanos (discreta), estatura (continua).

Tema 2: Conjuntos

Operaciones y propiedades fundamentales

Operaciones principales
\[ A \cup B = \{x : x \in A \text{ o } x \in B\} \]
\[ A \cap B = \{x : x \in A \text{ y } x \in B\} \]
\[ A' = \{x \in U : x \notin A\} \]
\[ A - B = \{x : x \in A \text{ y } x \notin B\} \]

Unión (∪)

Todo lo que está en A, en B, o en ambos. "A o B"

Ejemplo: {1,2} ∪ {2,3} = {1,2,3}

Intersección (∩)

Solo lo que está en A y en B a la vez. "A y B"

Ejemplo: {1,2} ∩ {2,3} = {2}

Diferencia (-)

Lo que está en A pero NO en B.

Ejemplo: {1,2} - {2,3} = {1}

Complemento (A')

Todo lo que NO está en A (dentro del conjunto universal).

⚠️
Error común

El conjunto vacío ∅ SIEMPRE es subconjunto de cualquier conjunto. Y cualquier conjunto es subconjunto de sí mismo.

Tema 3: Funciones

Funciones de probabilidad y distribución

Función de Masa (fmp)

Para variables discretas. Asigna probabilidad a cada valor.

Reglas: 0 ≤ P(x) ≤ 1 y ΣP(x) = 1

Función de Densidad (fdp)

Para variables continuas. El área bajo la curva = 1.

P(x = a) = 0 siempre en continuas

Función Acumulada (CDF)

F(x) = P(X ≤ x). Acumula probabilidades.

Siempre crece de 0 a 1

Propiedades clave
\[ \sum_{x} P(X=x) = 1 \quad \text{(discretas)} \]
\[ \int_{-\infty}^{\infty} f(x) \, dx = 1 \quad \text{(continuas)} \]
\[ P(a < X < b) = \int_{a}^{b} f(x) \, dx \]
Ejemplo con dado

F(x) = P(X ≤ x). Si F(3) = 0.5, significa que hay 50% de probabilidad de sacar 3 o menos.

Tema 4: Análisis Combinatorio

Permutaciones, combinaciones y factorial

Fórmulas esenciales
\[ n! = n \times (n-1) \times (n-2) \times ... \times 1 \]
\[ P(n,r) = \frac{n!}{(n-r)!} \quad \text{(orden importa)} \]
\[ C(n,r) = \frac{n!}{r!(n-r)!} \quad \text{(orden no importa)} \]
\[ P = n^r \quad \text{(con repetición)} \]
Situación Tipo Ejemplo
Ordenar TODOS los elementos Permutación simple: n! Ordenar 4 libros
Seleccionar y ordenar r de n Permutación: P(n,r) 1er, 2do, 3er puesto
Seleccionar r de n sin orden Combinación: C(n,r) Elegir equipo de 3
Repetir elementos P = n^r Contraseñas
💡
Truco para recordar

¿El orden importa? → Permutación
¿El orden NO importa? → Combinación
¿Se puede repetir? → n^r

Ejemplos rápidos

4! = 24  |  5! = 120  |  P(5,3) = 60  |  C(5,2) = 10
